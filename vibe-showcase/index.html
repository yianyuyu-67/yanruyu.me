猫&鱼

项目类型：移动端关系记录网页（PWA）

一个用于记录共同回忆、图片、文字和纪念日的移动端网页。奶油咖啡馆 × 手账治愈风双主题，支持添加到主屏幕离线使用。

核心功能

记录创建图片与文字编辑时间线浏览 纪念日查看双人加权评分情绪状态记录

我的工作

  • 产品结构设计（10+ 页面 / 路由体系）
  • 页面交互设计（左滑删除、双人评分流）
  • 移动端视觉设计（双主题设计系统）
  • 前端实现与功能测试迭代

技术栈

React 18 · Vite 5 · Framer Motion · Supabase · PWA

🔒 公开演示使用虚构数据，交互逻辑与实际项目一致；新增、编辑、删除只作用于本地演示数据。

关于这个项目

猫&鱼 是我独立完成的情侣私人生活记录 PWA：从需求梳理、信息架构、双主题视觉设计，到 React 前端实现与 Supabase 云端数据（图片存储 + 双人加权评分算法），全流程单人交付。

你正在操作的左边这台"手机"里运行的就是真实的项目代码——电脑上的鼠标点击、拖动、长按都被转换为移动端触摸行为，可以完整体验创建记录、浏览时间线、长按删除等交互。

公开演示版本使用虚构数据并完全隔离私人数据：不连接真实数据库，你的操作只作用于浏览器本地的演示数据，点「重新开始」即可复原。
