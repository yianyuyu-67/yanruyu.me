# Reconstruction notes

- Reference is a single oblique front-left photograph (896 x 1344); front silhouette, sage shell, sloped keyboard, ivory key field, platen, knobs, carriage rail, paper guide, ribbon and return lever are directly observed.
- Rear shell, underside, feet, exact key legends, internal typebar linkages and hidden fasteners are procedural approximations constrained by the visible silhouette and conventional typewriter construction.
- The preview is intentionally stylized for real-time Three.js use; it is not a measured CAD reproduction or texture projection.
