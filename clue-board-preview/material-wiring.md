# Material Evidence Wiring

The extracted board maps passed the source-evidence confidence threshold at 0.86 and are recorded in every stylized runtime material as calibration evidence. The implementation uses independent procedural/runtime materials for wood, cork, warm paper, cool map paper, grayscale photo print, pin metal, red cord, and translucent tape.

The source extraction is not treated as exact inverse rendering. Replaceable content uses generated canvas textures and stable content paths instead of baking the full reference onto one plane.
